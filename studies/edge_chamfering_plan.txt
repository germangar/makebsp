# Edge Chamfering (Normal Bending) — Implementation Plan

> [!CAUTION]
> **CRITICAL ARCHITECTURAL RULE:** We CANNOT modify the geometry boundaries. We can make subdivisions in the planar surfaces, but NOT move any of their boundary edges. Creating true geometric diagonal bevels would create holes in the geometry where this corner meets a perpendicular plane, like a wall corner meeting a floor. We can only manipulate the normals and create edge subdivisions, but nothing else. Never attempt to move external boundary edges or create physical bevels.

Smooth corner lighting at sharp structural edges by inserting thin border strips with bent vertex normals, creating an optical illusion of a rounded bevel without altering the actual collision geometry. Based on the audited design document `edge_chamfering.txt`.

## Architecture Overview (V3: Normal Bending)

Instead of creating true geometric bevels (which shrink structural boundaries), we employ a normal bending strategy:
1. **Inner Body Shifting:** The original flat face is shrunk inward by `chamferWidth`. This new "inner body" retains perfectly flat surface normals.
2. **Subdivision Strips:** A coplanar strip is spawned to fill the gap between the shrunk inner body and the original sharp corner.
3. **Normal Blending:** Vertices on the strip touching the inner body keep the flat face normal. Vertices on the strip touching the original sharp corner receive a blended normal (average of the two meeting faces).
4. **Result:** The lighting engine natively interpolates across the strip, producing a smooth gradient on an otherwise perfectly sharp geometric corner.

### Pipeline Integration

#### [MODIFY] q3map/bsp.c

In **both** `ProcessWorldModel` and `ProcessSubModel`, insert BEFORE `FixTJunctions`:

> [!IMPORTANT]
> `ChamferSurfaceEdges` MUST run before `FixTJunctions`. Running it after causes the algorithm to process fractured edges (slivered by T-junction resolution), resulting in torn and unaligned strips. Running it first operates on pristine polygons, allowing `FixTJunctions` to correctly sew up the new subdivisions afterward.

```c
if (chamferedges) {
    ChamferSurfaceEdges(e);
}
if (!notjunc) {
    FixTJunctions(e);
}
```

Add arg parsing in the command-line loop alongside `notjunc`:
```c
else if (!strcmp(argv[i], "-chamferedges"))
    chamferedges = qtrue;
else if (!strcmp(argv[i], "-chamferwidth"))
    chamfer_global_width = atof(argv[++i]);
```

### Core Implementation

#### [MODIFY] q3map/tjunction.c

Append all new code **at the end of the file**, after `FixTJunctions()`.

**`BuildSurfaceAdjacencyGraph(entity_t *e)`**
- Iterates all surfaces within the entity.
- Discards non-structural faces (patches, misc_models, decals).
- Compares vertex positions to find shared collinear chains.
- Registers bidirectional `surfaceNeighbor_t` links.

**`ChamferSurfaceEdges(entity_t *e)` — V3 Normal Bending Pass**
For each surface:
1. **Pass 1: Compute Inner Bodies (Insets)**
   - Uses `ComputeAllInsets()` to trace the geometric border of the shrunk inner polygon.
   - Saves these computed coordinates into a temporary `globalInsets[]` array.
2. **Pass 2: Generate Subdivision Strips**
   - Allocates new `mapDrawSurface_t` strips.
   - Emits quads bridging the `globalInsets` boundary to the original untouched vertices.
   - Applies the flat face normal to the inner boundary and the calculated `blendedNormal` to the outer geometric corner.
   - Enforces a Closed Perimeter Winding Order for all generated strips to allow Quake 3 to correctly auto-triangulate them.

**Perimeter Winding Order Pseudo-Code:**
When building the `strip->verts` array, vertices MUST be laid out so they trace the contiguous outer boundary of the polygon in a closed loop. Because `strip->side` is preserved, the compiler ignores explicit index buffers and attempts to auto-triangulate the loop natively.
```c
strip->numVerts = chainLen * 2;
strip->verts = malloc(strip->numVerts * sizeof(drawVert_t));
strip->numIndexes = 0; // Handled implicitly by SurfaceAsTristrip

for (int k = 0; k < chainLen; k++) {
    int vIdx = chain[k];

    // Outer edge: forward order [0..chainLen-1]
    strip->verts[k] = dsA->verts[vIdx];
    VectorCopy(blendedNormal, strip->verts[k].normal);

    // Inner edge: REVERSE order [chainLen..2*chainLen-1]
    // Reversing closes the perimeter loop: last outer -> first inner
    int innerSlot = chainLen + (chainLen - 1 - k);
    strip->verts[innerSlot] = globalInsets[i][vIdx];
    VectorCopy(faceNormal, strip->verts[innerSlot].normal);
}
```
3. **Pass 3: Replace Original Geometry**
   - Replaces the coordinates of the original large structural face with the computed `globalInsets` coordinates.

**`static ComputeAllInsets()`**
- Iterates all collected edges to build an `insetMap[vertexIndex]` lookup.
- Calculates an inward perpendicular offset. For CW triangles, `CrossProduct(edgeDir, faceNormal)`.
- For corners meeting two chamfered edges, calculates a standard 2D line-line intersection to find the mitre point.
- Clamps extreme mitre extensions (caused by highly acute angles) to a multiple of `chamferWidth`.

## Post-Implementation Errata

**Bug Fixes Integrated:**
1. **Triangle Stretching to Origin (0,0,0):** DrawSurfaces created via `AllocDrawSurf()` must have their `verts` and `indexes` explicitly allocated via `malloc`.
2. **Splits on Coplanar Surfaces:** Added a `CHAMFER_ANGLE_THRESHOLD` dot-product check (`> 0.866f`). Perfectly flat adjoining polygons are ignored.
3. **Missing Triangles (The Bow-Tie Winding Bug):** Quads generated for the strips MUST be laid out in a continuous perimeter loop (Outer forward, Inner reversed). If laid out as `[Outer0, Outer1, Inner0, Inner1]`, they form a figure-8 bow-tie. The BSP compiler (`SurfaceAsTristrip`) chokes on this, generating degenerate triangles and collapsing the strip into a single visible diagonal triangle. Explicit index buffers (`strip->indexes`) are completely ignored for brush faces, so the winding order is the only way to fix it.
4. **Z-Fighting Avoidance:** The algorithm achieves perfectly flush coplanar strips by strictly shrinking Face A, rather than just spawning strips blindly on top of it.
