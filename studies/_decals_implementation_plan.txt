# Implementation Plan: `_decal` Entity Integration (Audited)

This plan has been fully audited against the actual `makebsp` codebase. All struct fields, function signatures, emission paths, and lightmap allocation paths have been verified.

## Audit Findings & Corrections

> [!CAUTION]
> **8 bugs were found and corrected in the previous draft of this plan:**
> 1. **`entity_t` has no `numbrushes` field.** It uses a linked list (`e->brushes`). Cleanup is `e->brushes = NULL;` only.
> 2. **`C_NOMARKS` does not exist.** The correct flag is `si->surfaceFlags & SURF_NOMARKS` (defined in surfaceflags.h as `0x20`).
> 3. **`FilterFaceIntoTree` will crash.** It calls `FilterSideIntoTree_r` which dereferences `ds->side->planenum` (surface.c:1038). Our decal surfaces have `side = NULL`. Fix: route decals through `FilterMapDrawSurfIntoTree_r` (like `isHalo` surfaces do at surface.c:1846).
> 4. **`AllocateLightmapForSurface` will crash.** It dereferences `ds->side->planenum` at lightmaps.c:749. Fix: we must provide a valid `side_t` for decal surfaces so they can allocate lightmaps. If the target surface has no `side` (like a patch), we generate a dummy `side_t` using `FindFloatPlane` with the projection normal. We also inherit the `samplesize` from the originator surface.
> 5. **`EmitPlanarSurf` destroys alpha.** When `!ds->hasVertexColor`, it overwrites `color[0][3] = 255` at surface.c:1479. Fix: set `ds->hasVertexColor = 1` on decal surfaces so the baked alpha is preserved.
>    [POST-IMPLEMENTATION FIX: Setting `hasVertexColor = 1` forced Q3Map's `makelight` into legacy override mode where it reads the `-1` defaulted vertex color array from `ds->shaderInfo` causing the black silhouette issue. We changed this to `ds->hasVertexColor = -1` allowing it to bypass `EmitPlanarSurf`'s alpha reset without triggering Q3A's legacy RGB override behavior in `makelight`.]
> 6. **`FindTargetEntity` is `static`** in surface.c:1881. Fix: implement our own copy in `decals.c`.
> 7. **`_decal` entities will leak into the BSP entity lump.** `UnparseEntities` at bspfile.c:778 only strips `func_group` and `func_light`. Fix: add `_decal` to the strip list.
> 8. **`targetEntityNum` routing was wrong.** Decals project onto ALL geometry they overlap, not just the target entity's surfaces. The `target` key only provides the projection *vector* and *distance*. `MakeEntityDecals` must apply all projectors against all surfaces of the current entity, using AABB culling only.

### `MakeTextureMatrix()`
```c
// Builds dp->texMat[2][4] from the 3 triangle verts projected onto the projection plane
// Uses barycentric coordinate math from the spec (Section 3)
static qboolean MakeTextureMatrix(decalProjector_t *dp, vec3_t projNormal, float projDist,
                                   drawVert_t *a, drawVert_t *b, drawVert_t *c)
{
    // 1. Project all 3 verts onto the projection plane
    vec3_t pa, pb, pc;
    // pa = a->xyz - projNormal * (dot(a->xyz, projNormal) - projDist)
    
    // 2. Calculate barycentric basis denominator (bb)
    // bb = (b.st[0]-a.st[0])*(c.st[1]-a.st[1]) - (c.st[0]-a.st[0])*(b.st[1]-a.st[1])
    // if (fabs(bb) < 1e-8) return qfalse;  // Degenerate UVs
    
    // 3. Find S-vector: bary weights for (s=a.st[0]+1, t=a.st[1])
    // 4. Find T-vector: bary weights for (s=a.st[0], t=a.st[1]+1)
    // 5. Normalize S and T, build dp->texMat[0] and dp->texMat[1]
    //    dp->texMat[i][3] = a.st[i] - DotProduct(a->xyz, dp->texMat[i])
    return qtrue;
}
```

### `MakeDecalProjector()`
```c
static void MakeDecalProjector(shaderInfo_t *si, vec3_t projNormal, float distance,
                                drawVert_t *a, drawVert_t *b, drawVert_t *c)
{
    if (numDecalProjectors >= MAX_DECAL_PROJECTORS) {
        _printf("WARNING: MAX_DECAL_PROJECTORS reached\n");
        return;
    }
    decalProjector_t *dp = &decalProjectors[numDecalProjectors];
    memset(dp, 0, sizeof(*dp));
    dp->si = si;
    dp->numPlanes = 5;
    
    // 1. Front plane (the triangle itself)
    PlaneFromPoints(dp->planes[0], a->xyz, b->xyz, c->xyz); // sets normal and dist
    
    // 2. Back plane (parallel to front, pushed by 'distance' along projection vector)
    vec3_t backPoint;
    VectorMA(a->xyz, distance, projNormal, backPoint);
    VectorNegate(dp->planes[0].normal, dp->planes[1].normal);
    dp->planes[1].dist = DotProduct(backPoint, dp->planes[1].normal);
    
    // 3. Three side planes (triangle edges extruded along projection vector)
    vec3_t verts[3] = { a->xyz, b->xyz, c->xyz }; // copy for indexing
    for (int i = 0; i < 3; i++) {
        vec3_t extruded;
        VectorMA(verts[i], distance, projNormal, extruded);
        PlaneFromPoints(dp->planes[i + 2], verts[(i+1)%3], verts[i], extruded);
    }
    
    // 4. Bounding box & sphere from 6 points (3 verts + 3 projected verts)
    ClearBounds(dp->mins, dp->maxs);
    for (int i = 0; i < 3; i++) {
        AddPointToBounds(verts[i], dp->mins, dp->maxs);
        vec3_t proj;
        VectorMA(verts[i], distance, projNormal, proj);
        AddPointToBounds(proj, dp->mins, dp->maxs);
    }
    // center = midpoint of AABB, radius = distance from center to corner
    VectorAdd(dp->mins, dp->maxs, dp->center);
    VectorScale(dp->center, 0.5f, dp->center);
    vec3_t extent;
    VectorSubtract(dp->maxs, dp->center, extent);
    dp->radius = VectorLength(extent);
    
    // 5. Texture matrix
    if (!MakeTextureMatrix(dp, projNormal, DotProduct(a->xyz, projNormal), a, b, c)) {
        _printf("WARNING: Degenerate decal triangle UVs, skipping projector\n");
        return;
    }
    
    numDecalProjectors++;
}
```

### `ProcessDecals()` — Phase A
```c
void ProcessDecals(void)
{
    _printf("--- ProcessDecals ---\n");
    numDecalProjectors = 0;
    
    for (int i = 0; i < num_entities; i++)
    {
        entity_t *e = &entities[i];
        const char *classname = ValueForKey(e, "classname");
        if (strcmp(classname, "_decal") != 0) continue;
        
        // 1. Get decal origin
        vec3_t origin;
        GetVectorForKey(e, "origin", origin);
        
        // 2. Determine projection direction and distance
        vec3_t projNormal;
        float distance = 64.0f; // Reasonable default
        
        const char *targetName = ValueForKey(e, "target");
        if (targetName[0])
        {
            entity_t *targetEnt = FindTargetEntityByName(targetName);
            if (targetEnt)
            {
                vec3_t targetOrigin;
                GetVectorForKey(targetEnt, "origin", targetOrigin);
                VectorSubtract(targetOrigin, origin, projNormal);
                distance = VectorNormalize(projNormal, projNormal);
                // [POST-IMPLEMENTATION FIX: Setting distance directly to VectorNormalize(target_vector) 
                // perfectly aligns the back clipping plane onto the wall itself. This results in the 
                // interpolated alpha dropping cleanly to 0.0f at the wall, making the decal invisible. 
                // Distance should be decoupled into its own explicit property to allow projection 
                // *through* the target surface.]
            }
            else
            {
                _printf("WARNING: _decal entity %d target '%s' not found, defaulting down\n", i, targetName);
                VectorSet(projNormal, 0, 0, -1);
            }
        }
        else
        {
            _printf("WARNING: _decal entity %d has no target, defaulting down\n", i);
            VectorSet(projNormal, 0, 0, -1);
        }
        
        // 3. Extract triangles from entity's patches
        //    entity_t.patches is a linked list of parseMesh_t
        for (parseMesh_t *pm = e->patches; pm; pm = pm->next)
        {
            // [POST-IMPLEMENTATION FIX: Z-Fighting/Flickering occurred because the projector's origin
            // perfectly aligned with the generated surfaces. We had to iterate the raw patch geometry 
            // and inflate all control points outward by 1.0f along their individual normals *before* 
            // subdivision. This pushes the projector slightly off the wall, ensuring the volume cleanly
            // encompasses the geometry.]
            mesh_t *tess = SubdivideMesh(pm->mesh, 8.0f, 16.0f);
            // Iterate grid quads -> 2 triangles each
            for (int y = 0; y < tess->height - 1; y++) {
                for (int x = 0; x < tess->width - 1; x++) {
                    drawVert_t *v00 = &tess->verts[y * tess->width + x];
                    drawVert_t *v10 = &tess->verts[y * tess->width + x + 1];
                    drawVert_t *v01 = &tess->verts[(y+1) * tess->width + x];
                    drawVert_t *v11 = &tess->verts[(y+1) * tess->width + x + 1];
                    MakeDecalProjector(pm->shaderInfo, projNormal, distance, v00, v10, v01);
                    MakeDecalProjector(pm->shaderInfo, projNormal, distance, v10, v11, v01);
                }
            }
            FreeMesh(tess);
        }
        
        // 4. Extract triangles from entity's brushes (planar faces)
        //    entity_t.brushes is a linked list of bspbrush_t
        for (bspbrush_t *b = e->brushes; b; b = b->next)
        {
            for (int s = 0; s < b->numsides; s++)
            {
                side_t *side = &b->sides[s];
                if (!side->winding) continue;
                if (side->bevel) continue;
                winding_t *w = side->winding;
                // Fan-triangulate the winding
                for (int t = 2; t < w->numpoints; t++)
                {
                    // Construct temporary drawVert_t with xyz and st from winding
                    // (st will come from the side's texture mapping)
                    // MakeDecalProjector(side->shaderInfo, projNormal, distance, &dv0, &dv1, &dv2);
                }
            }
        }
        
        // 5. Delete entity geometry so it's not compiled into BSP
        //    NOTE: entity_t has NO numbrushes field; these are linked lists
        e->patches = NULL;
        e->brushes = NULL;
        // epairs are kept so classname can be checked in UnparseEntities strip logic
    }
    
    _printf("%d decal projectors created\n", numDecalProjectors);
}
```

### `TransformDecalProjector()` — Local space transform
```c
static void TransformDecalProjector(const decalProjector_t *in, vec3_t entityOrigin,
                                     decalProjector_t *out)
{
    *out = *in; // Copy everything
    
    // Translate AABB
    VectorSubtract(in->mins, entityOrigin, out->mins);
    VectorSubtract(in->maxs, entityOrigin, out->maxs);
    VectorSubtract(in->center, entityOrigin, out->center);
    
    // Translate planes (dist changes, normal stays the same)
    for (int i = 0; i < in->numPlanes; i++) {
        VectorCopy(in->planes[i].normal, out->planes[i].normal);
        out->planes[i].dist = in->planes[i].dist - DotProduct(in->planes[i].normal, entityOrigin);
    }
    
    // Adjust texture matrix translation component
    for (int i = 0; i < 2; i++) {
        // texMat[i][0..2] stay the same (direction doesn't change)
        out->texMat[i][3] = in->texMat[i][3]
            + in->texMat[i][0] * entityOrigin[0]
            + in->texMat[i][1] * entityOrigin[1]
            + in->texMat[i][2] * entityOrigin[2];
    }
}
```

### `ClipWindingEpsilonStrict()` — Local to decals.c
```c
// Strict clip with 0.0625f epsilon, matching q3map2 exactly.
// Returns back winding (inside frustum). Caller frees input.
static winding_t *ClipWindingEpsilonStrict(winding_t *in, vec3_t normal, vec_t dist)
{
    winding_t *front, *back;
    ClipWindingEpsilon(in, normal, dist, 0.0625f, &front, &back);
    if (front) FreeWinding(front);
    // Frustum planes point outward, so 'back' = inside the volume
    return back;
}
```

### `ProjectDecalOntoWinding()` — Core clipping + vertex generation
```c
static void ProjectDecalOntoWinding(decalProjector_t *dp, mapDrawSurface_t *ds,
                                     winding_t *w, vec3_t surfNormal)
{
    // 1. Backface cull
    if (DotProduct(dp->planes[0].normal, surfNormal) < -0.0001f)
    {
        FreeWinding(w);
        return;
    }
    
    // 2. Clip against all 5 frustum planes
    for (int p = 0; p < dp->numPlanes; p++)
    {
        winding_t *clipped = ClipWindingEpsilonStrict(w, dp->planes[p].normal, dp->planes[p].dist);
        FreeWinding(w);
        if (!clipped) return; // Completely outside
        w = clipped;
    }
    
    // 3. Emit the surviving winding as a new mapDrawSurface_t
    mapDrawSurface_t *newDs = AllocDrawSurf();
    newDs->isDecal = qtrue;
    newDs->hasVertexColor = 1;  // CRITICAL: prevents EmitPlanarSurf from overwriting alpha
    // [POST-IMPLEMENTATION FIX: Changed this to `newDs->hasVertexColor = -1` (see note in section 1)
    // to bypass legacy override code while letting makelight properly recognize the custom vertex color state.]
    newDs->shaderInfo = dp->si;
    newDs->numVerts = w->numpoints;
    newDs->verts = malloc(w->numpoints * sizeof(drawVert_t));
    memset(newDs->verts, 0, w->numpoints * sizeof(drawVert_t));
    newDs->mapBrush = NULL;
    
    // Inherit lightmap sample size from originator, unless overridden by decal shader
    newDs->samplesize = ds->samplesize;
    if (dp->si->lightmapSampleSize > 0)
        newDs->samplesize = dp->si->lightmapSampleSize;
    newDs->enforceSampleSize = ds->enforceSampleSize;

    // Provide a valid side_t so AllocateLightmapForSurface can generate lightmap projection vectors
    if (ds->side) {
        newDs->side = ds->side;
    } else {
        int planenum = FindFloatPlane(surfNormal, DotProduct(w->points[0], surfNormal));
        side_t *dummySide = malloc(sizeof(side_t));
        memset(dummySide, 0, sizeof(side_t));
        dummySide->planenum = planenum;
        newDs->side = dummySide;
    }
    
    for (int i = 0; i < w->numpoints; i++)
    {
        drawVert_t *dv = &newDs->verts[i];
        VectorCopy(w->points[i], dv->xyz);
        VectorCopy(surfNormal, dv->normal);
        
        // Calculate UVs from texture matrix
        dv->st[0] = DotProduct(dv->xyz, dp->texMat[0]) + dp->texMat[0][3];
        dv->st[1] = DotProduct(dv->xyz, dp->texMat[1]) + dp->texMat[1][3];
        
        // Calculate linear alpha fade
        float d  = DotProduct(dp->planes[0].normal, w->points[i]) - dp->planes[0].dist;
        float d2 = DotProduct(dp->planes[1].normal, w->points[i]) - dp->planes[1].dist;
        float alpha = (d + d2 > 0.0f) ? (255.0f * d2 / (d + d2)) : 0.0f;
        // [POST-IMPLEMENTATION FIX: Original formula required normal/vector sign agreements `(d + d2 < -0.0001f)`. 
        // When decal surfaces align heavily with projection direction, `d` and `d2` become positive leading to `0.0f` alpha.
        // We replaced `d` and `d2` with `fabs(d)` and `fabs(d2)` to ensure robust interpolation regardless of orientation.]
        if (alpha < 0) alpha = 0;
        if (alpha > 255) alpha = 255;
        
        dv->color[0][0] = 255;
        dv->color[0][1] = 255;
        dv->color[0][2] = 255;
        // [POST-IMPLEMENTATION FIX (`makelight` DownConvertDrawVerts BUG): makelight skips vertex lighting for 
        // lightmapped surfaces, leaving its internal light buffer for this surface at exactly `0.0f, 0.0f, 0.0f`.
        // At the end of compilation, `makelight` was blindly copying that black buffer back over `dv->color[0]`, 
        // obliterating our `255, 255, 255`. Since the decal used `rgbGen vertex`, multiplying texture * `0,0,0` 
        // turned the decal into a black silhouette. We modified `lightdata.c:DownConvertDrawVerts` to explicitly
        // skip `ds->lightmapNum >= 0`.]
        dv->color[0][3] = (byte)alpha;
    }
    
    FreeWinding(w);
}
```

### `MakeEntityDecals()` — Phase B
```c
void MakeEntityDecals(entity_t *e)
{
    if (numDecalProjectors == 0) return;
    
    vec3_t entityOrigin;
    GetVectorForKey(e, "origin", entityOrigin);
    
    int initialSurfs = numMapDrawSurfs; // Cache to avoid processing our own decals
    
    for (int i = 0; i < numDecalProjectors; i++)
    {
        decalProjector_t localDp;
        TransformDecalProjector(&decalProjectors[i], entityOrigin, &localDp);
        
        for (int s = e->firstDrawSurf; s < initialSurfs; s++)
        {
            mapDrawSurface_t *ds = &mapDrawSurfs[s];
            if (!ds->numVerts) continue;
            if (ds->isDecal) continue;
            if (ds->shaderInfo->autosprite) continue;
            if (ds->shaderInfo->surfaceFlags & SURF_NOMARKS) continue;
            
            // AABB overlap test
            vec3_t dsMins, dsMaxs;
            ClearBounds(dsMins, dsMaxs);
            for (int v = 0; v < ds->numVerts; v++)
                AddPointToBounds(ds->verts[v].xyz, dsMins, dsMaxs);
            
            if (localDp.mins[0] > dsMaxs[0] || localDp.maxs[0] < dsMins[0] ||
                localDp.mins[1] > dsMaxs[1] || localDp.maxs[1] < dsMins[1] ||
                localDp.mins[2] > dsMaxs[2] || localDp.maxs[2] < dsMins[2])
                continue;
            
            // Get surface normal
            vec3_t surfNormal;
            if (!ds->patch && !ds->miscModel && ds->side)
                VectorCopy(mapplanes[ds->side->planenum].normal, surfNormal);
            else
                VectorCopy(ds->verts[0].normal, surfNormal); // Approximate
            
            // Route by surface type
            if (ds->numIndexes > 0)
            {
                // Indexed geometry (patches, misc_models) — iterate triangles
                for (int t = 0; t < ds->numIndexes; t += 3)
                {
                    winding_t *w = AllocWinding(3);
                    w->numpoints = 3;
                    VectorCopy(ds->verts[ds->indexes[t  ]].xyz, w->points[0]);
                    VectorCopy(ds->verts[ds->indexes[t+1]].xyz, w->points[1]);
                    VectorCopy(ds->verts[ds->indexes[t+2]].xyz, w->points[2]);
                    ProjectDecalOntoWinding(&localDp, ds, w, surfNormal);
                }
            }
            else
            {
                // Convex polygon (planar brush face) — clip entire winding
                winding_t *w = AllocWinding(ds->numVerts);
                w->numpoints = ds->numVerts;
                for (int v = 0; v < ds->numVerts; v++)
                    VectorCopy(ds->verts[v].xyz, w->points[v]);
                ProjectDecalOntoWinding(&localDp, ds, w, surfNormal);
            }
        }
    }
}
```

## Verification Plan

### Build
- `make` — the Makefile uses `$(wildcard $(Q3MAP_DIR)/*.c)` so `decals.c` is automatically picked up.

### Regression
- Compile a map with NO `_decal` entities. `ProcessDecals` creates 0 projectors. `MakeEntityDecals` returns immediately. Zero behavioral change.

### Functional
1. Place a `_decal` entity with a patch targeting a wall → verify the decal appears on the wall with correct UVs.
2. Place a `_decal` targeting a `func_door` → verify it moves correctly with the door.
3. Check that the `_decal` entity itself does NOT appear in the final BSP entity lump.
4. Check that decal surfaces have `lightmapNum = -1` and no lightmap allocated.
5. Check that the vertex alpha fades from 255 (front) to 0 (back) across the projection distance.
