# Technical Design & Study: `func_trisoup` Implementation

This document outlines the architecture, pipeline integration, and API constraints for implementing the new `func_trisoup` entity in the modernized BSP toolchain.

---

## 1. Context & Architectural Overview

The goal is to introduce `func_trisoup`, a brush-based entity that:
1. Converts its non-caulk brush faces into unified, smoothed `MST_TRIANGLE_SOUP` (trisoup) meshes.
2. Applies normal smoothing along shared edges based on a mapper-defined `shadeangle` threshold.
3. Bypasses the chamfering pass on the initial implementation.
4. Automatically generates seamless lightmap UV coordinates via `xatlas` and optimizes geometry via decimation.

---

## 2. Detailed Technical Constraints of the Merging Pipeline

### The `miscModel` Gate
Currently, the compiler's post-processing passes (such as `MergeAdjacentTrisoups` and `MergeParentedTrisoups`) skip standard brush faces entirely using the following guard clause:
```c
if (!dsA->miscModel || dsA->numVerts <= 0 || dsA->numIndexes <= 0)
    continue;
```
Standard brush faces generated by the BSP compiler (`ClipSidesIntoTree`) are stored as flat convex N-gons. They:
* Do not have index buffers (`ds->indexes` is `NULL`, `ds->numIndexes == 0`).
* Have `ds->miscModel` set to `qfalse`.

### The Promotion Solution
To enable merging these faces into a trisoup without running chamfering, we must introduce a **promotion pass** that prepares standard faces for the trisoup pipeline:

1. **Candidate Filtering**: Identify standard drawsurfaces within the `func_trisoup` entity using `IsChamferCandidate(ds)` (filters out water, fog, nodraw, sky, etc.).
2. **Triangulation**: Explicitly triangulate each flat N-gon face into a triangle fan:
   * Allocate `ds->indexes` buffer for `(ds->numVerts - 2) * 3` indices.
   * Populate indices:
     ```c
     int idx = 0;
     for (int k = 1; k <= ds->numVerts - 2; k++) {
         ds->indexes[idx++] = 0;
         ds->indexes[idx++] = k;
         ds->indexes[idx++] = k + 1;
     }
     ds->numIndexes = idx;
     ```
3. **Flagging**: Set `ds->miscModel = qtrue` and `ds->planarDerived = qtrue` to mark them as promoted planar-derived trisoups.

## 3. Vertex Normal Smoothing by `shadeangle`

To achieve smooth Gouraud shading on curved structures (like columns or cylinders) while keeping sharp edges on flat intersections:

1. **Calculate Angle Threshold**: Read the `shadeangle` key from the entity (defaulting to e.g., $45^\circ$). Convert this to a dot product limit:
   $$\text{threshold\_dot} = \cos(\text{shadeangle} \cdot \frac{\pi}{180})$$
2. **Adjacency Check**: For any two surfaces sharing an edge:
   * Calculate the dot product of their face normals.
   * If the dot product is **greater than or equal to** $\text{threshold\_dot}$ (i.e., the angle between them is smaller than `shadeangle`):
     * The edge is classified as **smooth**. Add the neighbor face normal to the vertex normals along the shared edge.
   * If the dot product is **less than** $\text{threshold\_dot}$ (i.e., the angle between them is equal to or greater than `shadeangle`):
     * The edge is classified as **sharp**. Leave the vertex normals flat (unblended).

## 4. Pipeline Integration Plan

We will insert the `func_trisoup` compiler pass inside `ProcessSubModel()` in [q3map/bsp.c](file:///e:/CODE/antigravity/makebsp/q3map/bsp.c) immediately after `ClipSidesIntoTree(e, tree)`:

```c
void ProcessSubModel(void)
{
    // ...
    ClipSidesIntoTree(e, tree); // Generates original brush face drawsurfaces

    if (!strcmp(ValueForKey(e, "classname"), "func_trisoup"))
    {
        // 1. Synchronize collinear vertices across adjacent faces (T-junction prevention)
        InsertCollinearChamferVertices(e);

        // 2. Promote candidates to atomic trisoups (triangulation and flagging)
        PromoteBrushesToAtomicTrisoups(e);

        // 3. Calculate and smooth normals along edges below the shadeangle threshold
        SmoothTrisoupNormalsByShadeAngle(e);

        // 4. Merge adjacent trisoup surfaces sharing shaders/fog
        MergeAdjacentTrisoups(e);

        // 5. Cleanup degenerate triangles
        CleanupAllTrisoups(e);

        // 6. Decimate internal flat coplanar faces
        if (!nodecimateplanar)
        {
            DecimateAllTrisoups(e, qtrue);
        }

        // 7. Unwrap UVs via xatlas
        GenerateTrisoupUVs(e);
    }
    else
    {
        // Standard non-trisoup submodel pipeline
        // ...
    }
    
    // Continue allocating lightmaps and writing clusters
    AllocateLightmaps(e);
    FilterDrawsurfsIntoTree(e, tree);
    EndModel(node);
    FreeTree(tree);
}
```

## 5. Potential Verification & Future Considerations

* **Collinear Edge Matching**: The call to `InsertCollinearChamferVertices(e)` is essential to run *before* promotion and smoothing, ensuring that vertices line up perfectly. We should verify that `IsChamferCandidate` works identically for our promotion pass.
* **Lightmapping Compatibility**: Once flagged as `miscModel = qtrue`, `AllocateLightmaps` naturally routes the surfaces to `AllocateLightmapForMiscModel(ds)`, which relies on the UVs generated by `GenerateTrisoupUVs` / `xatlas`. This ensures perfect high-fidelity lightmaps.
