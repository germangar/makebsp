RadeonRays 2.0 source package
=============================

AMD GPUOpen currently points users who need OpenCL to the legacy RadeonRays 2.0
source branch:

  https://github.com/GPUOpen-LibrariesAndSDKs/RadeonRays_SDK/tree/legacy-2.0

This replaces an earlier ignored RR4.1 tree that was DX12/Vulkan-only and
therefore unsuitable for the planned OpenCL-based RR2 work.

Recommended integration configuration (when Phase 12 begins):

  -DRR_USE_OPENCL=ON
  -DRR_USE_VULKAN=OFF
  -DRR_USE_EMBREE=OFF
  -DRR_NO_TESTS=ON
  -DRR_ENABLE_STATIC=ON
  -DRR_SHARED_CALC=OFF
  -DRR_EMBED_KERNELS=ON

Rationale: build RR2/Calc/CLW from source for matching Windows/Linux builds,
embed OpenCL kernels, avoid Anvil/Vulkan and Embree dependencies, and prefer
static RadeonRays/Calc/CLW artifacts. The Khronos ICD loader sources and a
static libOpenCL.a are already vendored under libs/opencl for Linux use.
