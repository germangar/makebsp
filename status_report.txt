# Status Report: Chamfer Strip & Global Trisoup Adjacency Merging

## What We Are Doing
We are modernizing the Quake 3 / Warfork BSP compiler (`makebsp`) to produce clean, highly optimized geometry with chamfered edges and consolidated draw calls. We followed the plan outlined in "./studies/edge_chamfering_plan.txt".

Our focus has been on:
1. Merging chamfer strips with their parent planar fragments into atomic `MST_TRIANGLE_SOUP` meshes.
2. Transporting surface planarity information (`isPlanar`) through sidecar files for downstream lighting tools (`makelight`).
3. Performing a global adjacency-based optimization pass (`MergeAdjacentTrisoups`) to merge connected trisoups sharing shaders and rendering properties without exceeding the lightmap texture resolution budget.

## What We Accomplished

### 1. `isPlanar` Flag & Sidecar Serialization
- Added `qboolean isPlanar;` to `mapDrawSurface_t` (`q3map/qbsp.h`) and `extraSurface_t` (`shared/globals.h`).
- Updated all four emit sites in `q3map/surface.c` (`EmitPlanarSurf`, `EmitPatchSurf`, `EmitFlareSurf`, `EmitModelSurf`) to copy `ds->isPlanar` into `drawExtraSurfaces[numDrawSurfaces].isPlanar`.
- This ensures downstream tools like `makelight` know when a trisoup surface is strictly planar so exact planar lighting calculations can be applied.

### 2. Refactored `MergeParentedTrisoups`
- Renamed the earlier `MergeCoplanarTrisoups` to `MergeParentedTrisoups` in `q3map/tjunction.c`, `q3map/qbsp.h`, and `q3map/bsp.c`.
- Restricted this function strictly to merging parented chamfer strip fragments (`planarDerived && miscModel`).
- Sets `dsA->isPlanar = qtrue` on the resulting merged parented surface.
- Removed duplicate XAtlas UV generation from this step to defer UV packing until all merging is complete.

### 3. Implemented Global `MergeAdjacentTrisoups` Optimization Pass
- Created `MergeAdjacentTrisoups(entity_t *e)` in `q3map/tjunction.c`, called unconditionally in both `ProcessWorldModel` and `ProcessSubModel` after chamfering steps.
- Merges adjacent `MST_TRIANGLE_SOUP` surfaces that:
  - Share physical edge vertices (`SurfacesShareEdge` within `0.01f` epsilon).
  - Share the same `shaderInfo`, `fogNum`, `samplesize`, and `lightmapScale`.
  - Fit within the lightmap resolution budget: `ceil(sqrt(candidateArea) / samplesize * scale) <= (LIGHTMAP_WIDTH - 2)` (doubled when `!enforceSampleSize`).
- Properly tracks `isPlanar = isPlanar && allPlanar` (only remains planar if all merged components were planar and coplanar).
- **Two-Pass UV Generation**: Iterates over all surviving trisoup surfaces in a second pass and calls `GenerateAtomicUVsWithXAtlas(ds)` so every trisoup receives clean, non-overlapping lightmap UVs.

### 4. Verification & Performance Validation
- Compiled cleanly (`mingw32-make -j8`) and verified end-to-end execution via `testvfs.bat` on `wdm1_015.bsp`.
- Observed significant reduction in draw calls: consolidated contiguous brush faces and chamfer strips into unified batches of ~2,000 to ~7,000 triangles per shader (e.g. `concretebunker0068` with 2,932 vertices / 6,927 triangles).
- Confirmed that PVS cluster assignment (`FilterDrawsurfsIntoTree`) runs after merging, naturally placing references to merged trisoups in any PVS cluster they touch without popping.

### 5. Original Brush Edge Heuristic for Chamfering
- Implemented `IsOriginalBrushEdge` in `q3map/tjunction.c` to unilaterally evaluate if a chamfer candidate edge belongs to a face's original convex brush geometry.
- Resolves visual artifacts where structural faces would falsely chamfer around detail brushes or internal BSP/T-junction splits.
- Ensures chamfer bevels only spawn on authentic geometric boundaries (like room corners or pillar bases) while keeping surfaces flush underneath adjacent geometry.

### 6. Half-Space Corner Classification (`ClassifySurfaceSide`)
- Implemented `ClassifySurfaceSide` to evaluate signed distance of vertices against an arbitrary plane.
- Injected symmetric gate in `BuildSurfaceAdjacencyGraph` (ensuring only exact Convex `BACK/BACK` or Concave `FRONT/FRONT` corners are chamfered).
- Injected mismatched-opposite gate in `ChopTjunctions` to reject false splits when surfaces touch from behind (e.g. `FRONT/BACK`).

### 7. ChopTjunctions Enhancements (Zipper & Translucency)
- Reused `IsOriginalBrushEdge` to evaluate whether a split fragment in `ChopTjunctions` should be further subdivided.
- Stops the cascading "zipper effect" where detail stairs or multi-level contacts repeatedly slice across the interior of large structural faces by checking candidate edges against original brush bounding planes.
- Added strict translucency state matching (`CONTENTS_TRANSLUCENT`). Prevents transparent volumes (water, glass) from inducing splits across opaque structural faces and vice-versa.

### 8. True 3D Per-Vertex Blended Normals (`ComputeVertexBlendedNormal`)
- Replaced static per-edge normal assignment in `ChamferSurfaceEdges` with dynamic 3D normal accumulation using `ComputeVertexBlendedNormal`.
- At 3-way corners (cube tips, room corners), the helper dynamically sums and normalizes the pristine geometric plane normals (`mapplanes`) of all neighbor faces sharing a given vertex (`A + B + C`).
- Eliminates "shadow" shading artifacts across 3-way junctions, producing crisp, bright specular/diffuse corner highlights that perfectly align across intersecting strips.
- Cleaned up dead legacy code: removed the unused `blendedNormal` field from `surfaceChamferEdge_t` and deleted Pass 1 dead calculations.

### 9. Independent Concave Chamfer Width (`-chamferconcavewidth`)
- Introduced the `-chamferconcavewidth <float>` CLI switch (`chamfer_concave_width` global, defaulted to `-1.0f` fallback) to independently size concave joints (< 180° interior angle).
- Utilizes `FRONT/FRONT` half-space symmetry in `BuildSurfaceAdjacencyGraph` to set `isConcave = qtrue` on neighbor connections (`surfaceNeighbor_t`).
- Upgraded `ComputeAllInsets` and `ChamferSurfaceEdges` to track per-edge widths (`edges[numEdges].width`), enabling 2D line-line intersection math that cleanly joins faces where differing chamfer widths (e.g. 2.0 convex meeting 0.5 concave) intersect at a corner.
- **`-chamferconcavewidth 0` & Automatic Trisoup Conversion**: When set to `0` (or when adaptive geometry scaling brings edge widths below `MIN_CHAMFER_WIDTH = 0.5f`), both Pass 1 and Pass 2 skip strip generation for those edges without forming degenerate strips. Existing `MergeChamferStripsIntoParents()` automatically promotes these planar surfaces (`IsChamferCandidate(parent)`) into atomic trisoups (`miscModel = qtrue; planarDerived = qtrue;`) so they merge smoothly into adjacent trisoup groups without needing special flags.

### 10. Unified Chamfer Width Hierarchy & Entity/Shader Overrides
- Replaced the ambiguous `chamferWidth` terminology with strictly separated `chamferConvexWidth` and `chamferConcaveWidth` across all structs (`game_t`, `extraSurface_t`, `shaderInfo_t`).
- Built a deep control hierarchy in `DrawSurfaceForSide`:
  1. **Game/CLI Defaults**: Global `-chamferconvexwidth` / `-chamferconcavewidth` (or JSON profile fallbacks).
  2. **Shader Overrides**: `q3map_chamfer_convexwidth` and `q3map_chamfer_concavewidth` override the game defaults for specific materials.
  3. **Entity Overrides**: `chamfer_convexwidth` and `chamfer_concavewidth` override both globals and shaders on a per-entity basis (`ResolveSurfaceExtraProperties`).
- Resolved a critical ABI mismatch bug affecting `makelight.exe` that occurred after expanding the `shaderInfo_t` struct, causing corrupted memory offsets for lighting flags (e.g., `forceSunLight`, `twoSided`). Fixed via a full clean rebuild of the engine.

## Where We Are Going Next
- **Brush-Touching Triangulation Improvements**: Investigate and optimize situations where brush faces are split or triangulated due to how they touch adjacent brushes, aiming to avoid unnecessary surface splits before or during merging.
